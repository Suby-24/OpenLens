# 로컬 데이터 취급 원칙

OpenLens의 입력에는 방문 기록과 시청 기록이 포함될 수 있다. 원본은 사용자의 컴퓨터에서만 처리한다.

- GitHub에 원본 기록, 개인 프로필, API 키, 인증 파일 및 학습된 개인 모델을 올리지 않는다.
- 예제 데이터는 직접 작성하거나 식별 정보를 제거한 별도 파일로 만든다.
- 웹 기록을 가져올 때 로그인·메일·금융·의료 페이지와 검색어 등 민감한 항목을 먼저 제외할 수 있게 한다.
- 수집 및 분석에서 제외할 콘텐츠는 삭제하지 않아도 표시할 수 있게 설계한다.
- 분석 결과에는 데이터 기간, 표본 수, 출처와 모델의 불확실성을 표시한다.
- 클러스터 이름과 LLM이 제안한 주장은 검증된 사실과 구분한다.

`.gitignore`는 우발적인 파일 추가를 줄이지만 이미 Git에 추적된 파일은 보호하지 않는다. 커밋 전 변경 파일 목록을 확인한다.
