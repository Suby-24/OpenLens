# OpenLens 프로젝트 계획 v0.1

## 목적

한 사람이 소비한 콘텐츠에서 스스로 의식하지 못한 관심사와 정보 소비의 집중·변화를 발견한다. 결과는 관측된 콘텐츠 패턴으로 표현하며 사용자의 실제 신념으로 단정하지 않는다. 실제 배포보다 ML 문제 정의, 기준 모델, 평가 및 오류 분석을 우선한다.

## 첫 완성본

입력은 최근 3개월의 웹 방문 기록과 YouTube 시청 기록이다. 제목·설명·이용 가능한 본문을 분석하며 한국어를 중심으로 영어도 처리한다. 사용자가 파일을 직접 가져오는 로컬 단일 사용자 프로그램으로 만든다.

출력은 다음을 포함한다.

- 상위 카테고리에서 세부 주제까지 최대 3단계 관심사 지도
- 기간별 주제 소비량과 변화
- 출처 집중도와 유사 콘텐츠 반복 정도
- 같은 주제 안의 논점 클러스터 및 대표 콘텐츠
- 덜 소비한 논점 후보와 그 판단 근거
- 분류와 클러스터 이름을 수정할 수 있는 화면

처음에는 주제 집중과 논점 소비를 측정한다. 정확한 찬반 분류, 주장 추출 전용 모델 및 사용자의 신념 판정은 후속 실험으로 남긴다. 논점 클러스터는 서로 다른 주장이나 입장을 완벽하게 구분한다는 의미가 아니다.

## 카테고리 방식

상위 카테고리는 사람이 정의한 안정적인 분류표를 사용한다. 데이터에서 발견된 세부 관심사는 클러스터로 제안하고 사용자가 승인·수정한다. 여러 주제와 관련된 콘텐츠는 복수 카테고리를 허용하며, 확신이 낮은 콘텐츠는 미분류로 남긴다.

초기 상위 카테고리 **후보**: 건강·운동, 경제·금융, 기술, 과학, 정치·사회, 교육·학습, 직업·생산성, 문화·예술, 엔터테인먼트, 음식, 여행, 생활·소비, 스포츠, 인간관계, 기타·미분류. 실제 샘플을 확인한 뒤 경계와 이름을 확정한다.

## 모델 실험 순서

1. 제목 텍스트의 TF-IDF와 K-Means로 첫 콘텐츠 그룹을 확인한다.
2. 약 50건을 직접 검수해 평가셋을 만들고 상위 카테고리 기준을 정리한다.
3. TF-IDF + Logistic Regression을 상위 주제 분류 기준 모델로 학습한다.
4. 다국어 임베딩 + 분류기를 학습해 기준 모델과 비교한다.
5. 카테고리 내부에서 K-Means 등 클러스터링 방법을 비교한다.
6. 데이터가 충분한 주제에서 논점 클러스터를 만들고 대표 문장·콘텐츠로 검토한다.
7. 집계 지표를 구현하고 기간별 변화를 비교한다.
8. LLM은 선택적으로 클러스터 이름과 주장 후보의 임시 레이블을 생성한다. 사용자 검수 데이터와 구분해 저장한다.

분류는 사람이 확인한 데이터에서 F1과 카테고리별 오류를 살핀다. 클러스터는 대표 콘텐츠의 일관성과 기간을 달리했을 때의 안정성을 평가한다. LLM이 만든 레이블만으로 학습과 평가를 동시에 하지 않는다.

## 데이터 흐름

```text
개인 기록 파일
  → 최근 3개월 필터·민감 URL 제외·중복 처리
  → 콘텐츠 제목·설명·이용 가능한 본문
  → TF-IDF·다국어 임베딩
  → 상위 카테고리 + 세부 관심사 클러스터
  → 주제 내부 논점 클러스터
  → 사용자 검수
  → 관심사·집중도·변화 분석
  → 로컬 대시보드
```

## 단계별 완료 조건

| 단계 | 확인할 결과 |
| --- | --- |
| 첫 실험 | YouTube 기록 100~300건의 클러스터와 대표 단어를 재현 가능하게 출력 |
| 데이터 기반 | 웹·YouTube 기록을 동일한 콘텐츠 형식으로 가져오고 제외·중복 처리 가능 |
| ML 기반 | 상위 주제 분류 기준 모델과 임베딩 모델을 동일한 평가셋에서 비교 |
| 프로필 | 2주·1개월·3개월 관심사 분포, 출처·반복 지표와 근거 확인 |
| 논점 | 데이터가 충분한 주제에 논점 묶음과 대표 콘텐츠 표시 |
| 완성본 | 로컬에서 기록 가져오기, 분석, 결과 수정, 재실행이 가능 |

## 기술 선택

Python을 기본 언어로 사용한다. 첫 실험은 Jupyter와 scikit-learn으로 진행한다. 앱 단계에서 SQLite와 Streamlit을 도입한다. 다국어 임베딩과 딥러닝 비교가 필요해지면 PyTorch 기반 모델을 추가한다. 초기부터 모든 라이브러리와 서비스를 설치하지 않는다.

## 일정 추정

ML을 공부하며 주 10~15시간 진행하는 경우 첫 실험은 약 2~4주, 실제 사용할 수 있는 로컬 완성본은 약 6~9개월을 예상한다. 데이터 내보내기 형식, 본문 확보율, 수작업 검수량에 따라 달라질 수 있다.
