# OpenLens

**내가 보는 콘텐츠에서, 미처 몰랐던 나를 발견합니다.**

OpenLens는 콘텐츠 소비 기록을 바탕으로 관심사와 그 변화를 살펴보는 개인 머신러닝 프로젝트입니다. 궁극적으로는 스스로 알아차리지 못했던 편향을 마주하고, 평소 접하지 않던 다른 관점까지 만나도록 돕고자 합니다.

## 개발 동기

어느 순간부터 비슷한 콘텐츠만 보고 있다는 생각이 들었습니다. 좋아하는 것을 계속 보는 건 자연스럽지만, 그 사이 나와 다른 의견을 접할 기회가 줄어들고 있지는 않을까요?

내가 무엇에 관심을 두는지뿐 아니라, 어떤 주제에서 한쪽 의견만 반복해서 접하고 있는지도 궁금했습니다. 내가 알지 못했던 나의 편향을 직시하고, 그에 반하는 의견도 만나 보고 싶었습니다.

OpenLens는 이런 질문에서 출발했습니다. 직접 사용하는 도구를 만들면서 임베딩, 클러스터링, 분류 모델을 배우고 실험하는 과정도 함께 담고 있습니다.

## 지금까지 만든 결과

YouTube 시청 기록의 영상 제목을 분석해 **10개 상위 카테고리와 하위 카테고리로 분류**하고, 결과를 디렉토리 형태로 탐색할 수 있습니다.

상위 카테고리를 펼치면 하위 주제와 영상 수가 나타나고, 하위 주제를 펼치면 개별 영상을 확인할 수 있습니다. 학습 후에는 같은 HTML 보고서에 결과가 반영됩니다.

현재 분류는 제목을 기반으로 한 예측입니다. 잘못된 분류가 있을 수 있으며, 검토가 필요한 결과는 별도로 표시합니다. 관심사와 소비 패턴 분석을 위한 첫 단계로 사용하고 있습니다.

## 어떻게 작동하나요?

**기록 가져오기 → 제목 임베딩 → 군집 탐색·레이블링 → 상위·하위 분류 → 결과 탐색**

- **EmbeddingGemma**로 한국어·영어 제목을 벡터로 변환합니다.
- **K-Means**로 비슷한 콘텐츠를 묶고, 다양한 샘플을 골라 레이블을 검토합니다.
- **로지스틱 회귀**로 검토한 레이블을 학습해 나머지 영상을 분류합니다.
- **HTML 보고서**에서 카테고리별 결과와 개별 영상을 살펴봅니다.

초기에는 TF-IDF로 시작해 문맥을 반영하는 임베딩으로 확장했습니다. 모델의 결과를 직접 확인하고 수정하면서 개선하는 방식으로 개발하고 있습니다.

## 다음 목표

먼저 직접 사용할 수 있는 MVP를 완성하려 합니다.

- 카테고리별 소비 비중과 반복 시청 확인
- 기간별 관심사 변화 비교
- 분석의 근거가 되는 영상과 분류 상태 확인

이후에는 같은 주제 안에서 자주 접한 논점과 덜 접한 관점을 살펴보고, 다른 의견의 콘텐츠를 연결하고자 합니다. **편향 분석과 반대 관점 추천은 아직 구현되지 않았습니다.** 시청한 콘텐츠만으로 사용자의 신념을 단정하지 않습니다.
